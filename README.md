## 🚀 快速开始

### 全新安装（帮朋友装）

```bash
npm install -g @deepseek-ai/dsh
dsh  # 首次启动创建 ~/.dsh
# 然后按 DSH-Setup-Guide.md 第 3-5 节配置
```

### 迁移到新电脑

```
1. 新电脑安装 DSH
2. 拷贝 P0+P1 配置文件（见手册 §迁移注意事项）
3. cd ~/.dsh/profiles/web && pnpm install
4. 拷贝 P2 文件（skills, skins, presets）
5. dsh → 验证 http://127.0.0.1:3080
```

## ⚠️ 安全提示

- `.credentials.yaml` 和 `.env` 包含 API 密钥，**绝不要提交到 Git**
- 本仓库所有示例中的密钥均已替换为占位符
- `danger-full-access` 模式有风险，帮朋友安装时建议先用默认的 `ask` 模式
